# Oplify

**Oplify Message** is a multi-tenant WhatsApp Business API platform. Each tenant
connects its own WhatsApp Business Account and manages contacts, templates,
broadcasts, a shared team inbox, bookings and billing.

| Repository                                                                   | What it is                                     |
| ---------------------------------------------------------------------------- | ---------------------------------------------- |
| [oplify-messaging-api](https://github.com/OplifyDevOrg/oplify-messaging-api) | Node 20 / Express 5 / Postgres / Redis backend |
| [oplify-messaging-app](https://github.com/OplifyDevOrg/oplify-messaging-app) | React 19 / Vite dashboard                      |

New here? Start with [CONTRIBUTING.md](https://github.com/OplifyDevOrg/.github/blob/main/CONTRIBUTING.md),
then `make up` in the API repo.

Work is tracked on the [Oplify Delivery](https://github.com/orgs/OplifyDevOrg/projects/1) board.
